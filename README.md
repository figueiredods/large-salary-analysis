# 📊 Large Salary Analysis

An Exploratory Data Analysis (EDA) and data pipeline project in Python analyzing compensation drivers across **6,694 cleaned employment records**. This project evaluates how academic credentials, years of experience, and job roles impact annual compensation through clear visual insights.

## 📈 Visual Exploratory Data Analysis

The project generates three core visualization outputs via :

### 1. Salary Distribution ()
* **Histogram & KDE Plot**: Visualizes the density and spread of annual salaries ().
* **Central Tendency Markers**: Features explicit vertical reference lines for mean and median salary levels to evaluate skewness across the workforce.

### 2. Compensation by Education Level ()
* **Box Plot Comparison**: Evaluates salary distribution across four academic tiers: High School, Bachelor's, Master's, and PhD.
* **Degree Progression**: Illustrates how higher credentials shift compensation baselines and impact salary variance.

### 3. Experience Progression ()
* **Scatter Plot & Regression Fit**: Plots individual compensation against total years of professional experience.
* **Trend Line**: Overlays a linear regression line to visualize return on years worked.
